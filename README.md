# 24-Hour Weekly Pricing Clock

![Python](https://img.shields.io/badge/Python-3.14-blue)
![Matplotlib](https://img.shields.io/badge/Made_with-Matplotlib-orange)

A polar chart visualization rendering a 24-hour weekly pricing clock for Tijuana, Mexico (PDT timezone).

## Quick Start

```bash
source .venv/bin/activate
python main.py
```

Generates `perfected_pricing_clock.png` (300 DPI).
